# 1.所得税核算的基本原理

## 1.1核心原理：资产负债表债务法

所得税会计的本质就一句话：**以资产负债表为基础，通过比较资产/负债的账面价值与计税基础的差异，确认递延所得税，从而倒挤出所得税费用。**
## 1.2 核算流程

### 第一步：确定资产/负债的账面价值与计税基础

| 项目 | 账面价值 | 计税基础 |
| :--- | :--- | :--- |
| **资产** | 按会计准则确认的金额 | 未来期间税法允许税前扣除的金额 |
| **负债** | 按会计准则确认的金额 | 账面价值 − 未来期间税法允许扣除的金额 |
> 💡 **记忆口诀**：资产的计税基础看"未来能扣多少"，负债的计税基础看"未来不能扣多少"。

> [!note]
> 负债代表一项**义务**，当你未来履行这项义务（花钱/交付）时，税法可能允许你把这笔支出拿去抵税。所以计税基础反映的是——**这项负债中，未来"不能再给你带来税收利益"的部分**。
> 
> 负债的计税基础，本质上回答一个问题：
>   "这笔负债，未来了结时，还能不能给我省税？"
>   - 能省（未来可扣）→ 计税基础变小 → 产生可抵扣差异 → DTA
>   - 不能省（未来不可扣）→ 计税基础 = 账面 → 没差异 → 不用管
### 第二步：识别暂时性差异

$$\text{暂时性差异} = \text{账面价值} - \text{计税基础}$$

| 差异类型 | 条件 | 确认 |
| :--- | :--- | :--- |
| **应纳税暂时性差异** | 资产：账面 > 计税基础；负债：账面 < 计税基础 | → 递延所得税**负债**（DTL） |
| **可抵扣暂时性差异** | 资产：账面 < 计税基础；负债：账面 > 计税基础 | → 递延所得税**资产**（DTA） |
### 第三步：确认递延所得税

$$\text{递延所得税资产/负债（期末余额）} = \text{暂时性差异} \times \text{适用税率}$$$$\text{本期递延所得税费用} = \text{期末余额} - \text{期初余额}$$
> ⚠️ 注意：DTA 的确认要以"未来很可能取得足够应纳税所得额"为前提，这是考试常考陷阱。
### 第四步：倒挤所得税费用

$$\text{所得税费用} = \text{当期所得税} + \text{递延所得税费用}$$

其中：
- **当期所得税** = 应纳税所得额 × 税率（按税法口径算）
- **递延所得税费用** = ΔDTL − ΔDTA（仅计入损益的部分）

 **一张图总结**

```
会计利润 ──纳税调整──→ 应纳税所得额 ──×税率──→ 当期所得税（交给税局的）
    │                                              │
    │  账面价值 vs 计税基础 → 暂时性差异 → DTA/DTL  │
    │                                    ↓          │
    │                            递延所得税费用       │
    │                                    ↓          │
    └──────────────→  所得税费用 = 当期 + 递延  ←────┘
```

# 2. 资产的计税基础

- 资产的计税基础,是指企业收回资产账面价值过程中,计算应纳税所得额时按照税法规定可以自应税经济利益中抵扣的金额。
- 资产的计税基础=某一项资产在**未来期间**计税时可以税前扣除的金额
## 2.1 固定资产

- 以各种方式取得的固定资产,**初始确认时**按照会计准则规定确定的入账价值基本上是被税法认可的,即取得时其账面价值一般等于计税基础。
- 固定资产在持有期间进行**后续计量时**,由于会计与税法规定就**折旧方法、折旧年限以及固定资产减值**准备的提取等处理的不同,造成固定资产的账面价值与计税基础的差异。
### 2.1.1 折旧方法、折旧年限产生的差异

 ①折旧方法产生的差异

| 维度 | 规定内容 |
| --- | --- |
| **会计准则** | 企业应当根据与固定资产有关的经济利益的预期消耗方式合理选择折旧方法,如:<br>- 年限平均法<br>- 双倍余额递减法<br>- 年数总和法等 |
| **税法** | 除某些按照规定可以加速折旧的情况外,基本上可以税前扣除的是按照**年限平均法**计提的折旧 |

**【参考:税法允许加速折旧的情形】**

**a. 企业所得税法第三十二条规定**
- 企业的固定资产由于技术进步等原因,确需加速折旧的,可以:
  - **缩短折旧年限**
  - **采取加速折旧的方法**

**b. 企业所得税法实施条例第九十八条规定**
可以采取加速折旧的固定资产包括:
- 由于技术进步,产品更新换代较快的固定资产
- 常年处于强震动、高腐蚀状态的固定资产

具体方法:
- **缩短折旧年限**:最低折旧年限不得低于税法规定折旧年限的**60%**
- **加速折旧方法**:可以采取双倍余额递减法或年数总和法

---

 ②折旧年限产生的差异

| 维度 | 规定内容 |
| --- | --- |
| **会计准则** | 折旧年限由企业根据固定资产的性质和使用情况**合理确定** |
| **税法** | 对每一类固定资产的**最低折旧年限**作出了明确规定 |
| **差异后果** | 企业会计处理确定的折旧年限与税法规定不同时,会因每期折旧额的差异产生固定资产在资产负债表日账面价值与计税基础的差异 |

**【参考:税法规定的最低折旧年限】**

企业所得税法实施条例第六十条规定,除国务院财政、税务主管部门另有规定外,固定资产计算折旧的**最低年限**如下:

| 固定资产类别 | 最低折旧年限 |
| --- | --- |
| 房屋、建筑物 | 20年 |
| 飞机、火车、轮船、机器、机械和其他生产设备 | 10年 |
| 与生产经营活动有关的器具、工具、家具等 | 5年 |
| 飞机、火车、轮船以外的运输工具 | 4年 |
| 电子设备 | 3年 |
### 2.1.2 因计提固定资产减值准备产生的差异

**差异产生原因:**

持有固定资产的期间内,在对固定资产计提了减值准备以后,因税法规定企业计提的资产减值准备在发生实质性损失前不允许税前扣除,在有关减值准备转变为实质性损失前,也会造成固定资产的账面价值与计税基础的差异。

**核心原则对比:**

| 会计准则         | 税法            |
| ------------ | ------------- |
| **谨慎性原则**    | **据实扣除原则**    |
| 预期损失可以计提减值准备 | 只有实质性损失才能税前扣除 |
### 2.1.3 税法其他规定产生的差异

《关于设备、器具扣除有关企业所得税政策的公告》（财税[2023]第37号）规定，企业在2024年1月1日至2027年12月31日期间新**购进**的设备、器具（指除房屋、建筑物以外的固定资产），单位价值不超过500万元的，允许一次性计入当期成本费用在计算应纳税所得额时扣除，不再分年度计算折旧。

> [!example] 例题·计算分析题
> A公司于2×22年12月20日取得的某项固定资产，原价为$750$万元，使用年限为$10$年，会计上采用年限平均法计提折旧，净残值为$0$。税法规定该类（由于技术进步、产品更新换代较快的）固定资产采用加速折旧法计提的折旧可予税前扣除，该企业在计税时采用双倍余额递减法计提折旧，使用年限及净残值与会计相同。2×24年12月31日，A公司估计该项固定资产的可收回金额为$550$万元，该固定资产以前期间未计提减值准备。
>
> > [!check]- 答案与解析
> > **正确答案：**
> > 2×24年递延所得税负债当期发生额为 **-1.25万元**，会计分录为：
> > 借：递延所得税负债　　　　　　　 1.25
> > 　贷：所得税费用　　　　　　　　　 1.25
> >
> > **深度解析：**
> > **第一步：计算2×24年末计提减值准备前的账面价值。**
> > 会计年折旧额 $= 750 / 10 = 75$ 万元。
> > 2×24年12月31日，计提减值准备前的账面价值 $= 750 - 75 \times 2 = 600$ 万元。
> >
> > **第二步：判断并计算固定资产减值准备。**
> > 可收回金额为$550$万元，低于账面价值$600$万元，应计提减值准备 $= 600 - 550 = 50$ 万元。
> > 计提减值后账面价值 $= 600 - 50 = 550$ 万元。
> >
> > **第三步：计算2×24年末的计税基础（双倍余额递减法）。**
> > 年折旧率 $= 2 / 10 = 20\%$。
> > - 2×23年折旧额 $= 750 \times 20\% = 150$ 万元，年末计税基础 $= 750 - 150 = 600$ 万元。
> > - 2×24年折旧额 $= 600 \times 20\% = 120$ 万元。
> > 2×24年末计税基础 $= 750 - 150 - 120 = 480$ 万元。
> > （或直接计算：$750 - 750 \times 20\% - 600 \times 20\% = 480$ 万元）
> >
> > **第四步：计算暂时性差异及递延所得税余额。**
> > 2×24年末资产账面价值$550$万元 > 计税基础$480$万元，产生**应纳税暂时性差异** $= 550 - 480 = 70$ 万元。
> > 应确认的递延所得税负债**余额** $= 70 \times 25\% = 17.5$ 万元。
> >
> > **第五步：计算当期递延所得税发生额并编制分录。**
> > 首先需计算2×23年末已确认的递延所得税负债：
> > - 2×23年末账面价值 $= 750 - 75 = 675$ 万元。
> > - 2×23年末计税基础 $= 750 - 150 = 600$ 万元。
> > - 应纳税暂时性差异 $= 675 - 600 = 75$ 万元。
> > - 2×23年确认递延所得税负债 $= 75 \times 25\% = 18.75$ 万元。
> >
> > 2×24年递延所得税负债当期发生额 $= 期末余额 - 期初余额 = 17.5 - 18.75 = -1.25$ 万元。
> > 因此，本期应**转回**递延所得税负债$1.25$万元。
> > 会计分录：
> > 借：递延所得税负债　　　　　　　 1.25
> > 　贷：所得税费用　　　　　　　　　 1.25
> >
> > **💡 易错点提示：**
> > 1.  **递延所得税核算的是“余额”与“发生额”**：不能直接根据当期期末的应纳税暂时性差异$70$万元乘以税率得出当期所得税费用。必须用期末递延所得税负债余额$17.5$万元减去期初余额$18.75$万元，才能得出当期应**转回**$1.25$万元。
> > 2.  **减值准备对差异的影响**：计提固定资产减值准备会**降低资产的账面价值**，但**不影响其计税基础**（税法不认可减值损失）。这使得账面价值与计税基础的差额（暂时性差异）发生变动，进而影响递延所得税。
> > 3.  **会计折旧与税法折旧的区分**：本题核心差异源于会计采用直线法，而税法采用双倍余额递减法，导致前期税法折旧额大于会计折旧额，产生应纳税暂时性差异。

## 2.2 无形资产

- 除内部研究开发形成的无形资产以外，其他方式取得的无形资产，**初始确认时**按照会计准则规定确定的入账价值与按照税法规定确定的计税基础之间**一般不存在差异**。
- 无形资产在**后续计量时**，会计与税法的差异主要产生于是否需要摊销、摊销方法和年限的差异及无形资产减值准备的提取。
### 2.2.1 内部研究开发形成的无形资产

**核心税法规定：加计扣除**

企业为开发新技术、新产品、新工艺发生的研究开发费用，未形成无形资产计入当期损益的，在按照规定据实扣除的基础上，按照研究开发费用的**200%** 加计扣除；形成无形资产的，按照无形资产成本的**200%** 摊销。

**差异分析：**

| 情形 | 账面价值 | 计税基础 | 差异 |
| :--- | :--- | :--- | :--- |
| 研发支出**费用化** | 0（已计入当期损益） | 0 | 无暂时性差异（加计扣除影响的是当期应纳税所得额） |
| 研发支出**资本化** | 原价 − 累计摊销 | （原价 × 200%）− 累计税法摊销 | 账面 < 计税基础 → 可抵扣暂时性差异 |

> ⚠️ **关键考点：内部研发形成的无形资产，虽然产生可抵扣暂时性差异，但因其初始确认时既不影响会计利润也不影响应纳税所得额，属于"初始确认豁免"，不确认递延所得税资产。** 详见第5节。

> [!example] 例题·计算分析题
> 甲公司当期发生研究开发支出共计$1000$万元，其中研究阶段支出$200$万元，开发阶段符合资本化条件前发生的支出$100$万元，符合资本化条件后至达到预定用途前发生的支出$700$万元。税法规定，研发费用加计扣除比例为$200\%$。假定开发形成的无形资产于当期期末达到预定用途，尚未开始摊销。
>
> > [!check]- 答案与解析
> > **正确答案：**
> > 费用化部分不产生暂时性差异；资本化部分账面价值$700$万元，计税基础$1400$万元，产生可抵扣暂时性差异$700$万元，但**不确认DTA**。
> >
> > **深度解析：**
> > **第一步：确定费用化与资本化金额。**
> > - 费用化支出 $= 200 + 100 = 300$ 万元 → 计入当期管理费用
> > - 资本化支出 $= 700$ 万元 → 确认为无形资产
> >
> > **第二步：计算计税基础。**
> > - 费用化部分：当期税前扣除 $300 \times 200\% = 600$ 万元（加计扣除$300$万元调减应纳税所得额），不产生资产负债表项目，无暂时性差异。
> > - 资本化部分：无形资产计税基础 $= 700 \times 200\% = 1400$ 万元。
> >
> > **第三步：判断暂时性差异。**
> > 账面价值$700$万元 < 计税基础$1400$万元，产生可抵扣暂时性差异 $= 1400 - 700 = 700$ 万元。
> >
> > **第四步：判断是否确认DTA。**
> > 该差异产生于无形资产的**初始确认**，且该交易不是企业合并，同时在初始确认时既不影响会计利润也不影响应纳税所得额，属于**初始确认豁免**，**不确认递延所得税资产**。
> >
> > **💡 易错点提示：**
> > 1. 加计扣除产生的差异，在**费用化**环节体现为当期纳税调减，不形成暂时性差异；在**资本化**环节体现为计税基础放大，形成暂时性差异但不确认DTA。
> > 2. 后续摊销期间，该差异随摊销逐期转回，转回时也**不确认递延所得税**，但加计摊销的部分会调减当期应纳税所得额。

### 2.2.2 无形资产的后续计量

- 会计准则规定，使用寿命不确定的无形资产**不摊销**，但需每年进行减值测试。
- 税法规定，企业取得的无形资产成本，应在**不低于10年**的期限内摊销。

- 会计：账面价值 = 原价 − 减值准备（无累计摊销）
- 税法：计税基础 = 原价 − 累计税法摊销额

> 💡 由于税法每年在扣除摊销，计税基础逐年减小，而会计不摊销，账面价值不变（不考虑减值时），因此：**账面价值 > 计税基础 → 应纳税暂时性差异 → DTL**

与固定资产相同，税法不认可会计上计提的无形资产减值准备。计提减值后：
- 账面价值下降（原价 − 累计摊销 − 减值准备）
- 计税基础不变（原价 − 累计税法摊销）
- 若账面 < 计税基础 → 可抵扣暂时性差异 → DTA

> [!example] 例题·单选题（2024）
> 甲公司适用的企业所得税税率为25%。2×24年1月1日，甲公司递延所得税资产和递延所得税负债的账面余额为零。当日，甲公司以6 000万元取得某项商标权，甲公司管理层判断无法合理估计该商标权的预计使用年限，从而将其作为使用寿命不确定的无形资产。2×24年12月31日，甲公司对该商标权进行减值测试的结果显示发生减值400万元。企业所得税法规定，企业取得商标权发生的成本6 000万元按10年期限采用直线法摊销，摊销金额允许在当期税前扣除。不考虑其他因素，甲公司2×24年12月31日资产负债表中列报的递延所得税负债金额是（　　）。
> 
> A. 50万元  
> B. 100万元  
> C. 150万元  
> D. 250万元
>
> > [!check]- 答案与解析
> > 
> > **正确答案：A**
> >
> > **深度解析：**
> > 
> > **第一步：确定商标权的账面价值**
> > - 初始成本：**6 000万元**
> > - 会计处理：使用寿命不确定，**不进行摊销**
> > - 减值损失：**400万元**
> > - 期末账面价值 = $6\,000 - 400 = 5\,600$（万元）
> >
> > **第二步：确定商标权的计税基础**
> > - 税法规定：按**10年直线法摊销**
> > - 2×24年税前扣除的摊销额 = $6\,000 \div 10 = 600$（万元）
> > - 期末计税基础 = $6\,000 - 600 = 5\,400$（万元）
> >
> > **第三步：计算暂时性差异**
> > - 账面价值（5 600万元）**>** 计税基础（5 400万元）
> > - 产生**应纳税暂时性差异** = $5\,600 - 5\,400 = 200$（万元）
> >
> > **第四步：确认递延所得税负债**
> > - 递延所得税负债 = $200 \times 25\% = 50$（万元）
> >
> > **💡 易错点提示：**
> > 1. **会计与税法差异**：会计上使用寿命不确定的无形资产不摊销，但税法要求必须摊销，这是产生暂时性差异的根源
> > 2. **减值的税法处理**：会计上计提的减值损失**不能税前扣除**，不影响计税基础的计算
> > 3. **差异性质判断**：账面价值 > 计税基础时，形成的是**应纳税暂时性差异**，对应确认递延所得税**负债**（而非资产）

## 2.3 以公允价值计量的资产

### 2.3.1 以公允价值计量且其变动计入当期损益的金融资产

**核心差异：** 会计按公允价值计量，税法按取得时的成本计量。

| 维度 | 会计 | 税法 |
| :--- | :--- | :--- |
| **初始计量** | 公允价值（交易费用计入当期损益） | 取得成本 |
| **后续计量** | 公允价值变动计入当期损益 | 不认可公允价值变动，持有期间计税基础不变 |
| **处置时** | 确认投资收益 | 按实际处置价款与计税基础的差额计入应纳税所得额 |

**差异分析：**

| 公允价值变动方向 | 账面价值 vs 计税基础 | 暂时性差异类型 | 确认 |
| :--- | :--- | :--- | :--- |
| 公允价值**上升** | 账面 > 计税基础 | 应纳税暂时性差异 | DTL |
| 公允价值**下降** | 账面 < 计税基础 | 可抵扣暂时性差异 | DTA |

### 2.3.2 以公允价值计量且其变动计入其他综合收益的金融资产

企业持有的**分类为**以公允价值计量且其变动计入其他综合收益的金融资产（其他债权投资），以及**指定为**以公允价值计量且其变动进入其他综合收益的金融资产（其他权益工具投资），其计税基础的确定，与以公允价值计量且其变动计入当期损益的金融资产类似，可比照处理。

- 会计准则确定的账面价值=公允价值
- 税法确定的计税基础=取得成本

差异分析与交易性金融资产相同，但对应的递延所得税**不计入所得税费用**，而是计入**其他综合收益**。

> ⚠️ **这是一个极其重要的考点：递延所得税的对应科目不一定是所得税费用！** 当暂时性差异的产生源于计入其他综合收益的交易，对应的递延所得税也应计入其他综合收益。
### 2.3.3 以公允价值计量的投资性房地产

采用公允价值模式计量的投资性房地产，会计上不计提折旧或摊销，以期末公允价值为账面价值。税法上仍按照固定资产或无形资产的规定计提折旧或摊销，且不认可公允价值变动。

- 账面价值 = 期末公允价值
- 计税基础 = 原价 − 累计税法折旧/摊销

> 💡 公允价值模式下的投资性房地产，差异方向取决于公允价值与计税基础的大小关系，需要具体计算判断。

## 2.4 其他资产

### 2.4.1 存货

存货的账面价值 = 成本 − 存货跌价准备。税法不认可存货跌价准备，计税基础 = 历史成本。

- 计提跌价准备后：账面 < 计税基础 → 可抵扣暂时性差异 → DTA

### 2.4.2 应收账款等金融资产（按摊余成本计量）

会计上按预期信用损失模型计提坏账准备（信用减值损失），税法规定未经核定的准备金支出不得税前扣除。

- 账面价值 = 应收账款余额 − 坏账准备
- 计税基础 = 应收账款余额（税法不认可坏账准备）
- 账面 < 计税基础 → 可抵扣暂时性差异 → DTA

# 3. 负债的计税基础

$\text{负债的计税基础} = \text{账面价值} - \text{未来期间计算应纳税所得额时按照税法规定可予抵扣的金额}$

> 💡 **核心理解**：负债的计税基础反映的是这笔负债中"未来不能再给你带来税收利益"的部分。如果未来履行义务时税法允许扣除，则计税基础 < 账面价值，产生可抵扣暂时性差异。

> [!note]- 理解
> **负债的计税基础，本质上就是在问：这笔负债里，有多少是税务局"已经认过账"的、未来不能再让你少交税的部分。**
> 
> $$\text{负债的计税基础} = \text{账面价值} - \text{未来可税前扣除的金额}$$
> 
> 你把它翻译成大白话就是：
> 
> > 账面上欠了100万 → 未来履行这个义务的时候，税法允许你扣掉60万 → 那计税基础就是40万。
> 
> 这40万是什么意思？就是**税务局眼里"已经消化掉的、不会再给你税收好处的"那部分**。
> 
> 这是最关键的一步。你回忆一下资产的计税基础：
> 
> $$\text{资产的计税基础} = \text{未来可税前扣除的金额}$$
> 
> 资产是"未来能给你带来经济利益的东西"，所以税务局关心的是：未来还能扣多少。
> 
> 负债呢？负债是"未来要流出经济利益的东西"。当你未来真的把钱花出去履行义务的时候，税法可能允许你扣除这笔支出。所以负债的计税基础要**反过来**——用账面价值减掉未来能扣的，剩下的才是"税务上已经处理完毕的部分"。
> 
> **一句话总结这个对称关系：**
> - 资产的计税基础 = 未来能扣的（还没用的税收利益）
> - 负债的计税基础 = 账面价值 - 未来能扣的 = 已经用掉的税收利益
> 
>  **一个帮你秒判的思维模型**：
>  
> 遇到任何负债，你就问自己一个问题：
> 
> > **"未来我履行这个义务花钱的时候，税务局会不会额外让我少交税？"**
> 
> - 会 → 未来可扣 > 0 → 计税基础 < 账面价值 → **可抵扣暂时性差异 → 递延所得税资产**
> - 不会 → 未来可扣 = 0 → 计税基础 = 账面价值 → **无差异**

## 3.1 预计负债

### 3.1.1 因产品质量保证确认的预计负债

| 维度 | 会计 | 税法 |
| :--- | :--- | :--- |
| **确认时点** | 销售时即按预计保修费用确认预计负债 | 实际发生保修支出时才允许税前扣除 |
| **计税基础** | 账面价值 − 未来可扣除金额 = 0 | 因为未来实际发生时全额可扣 |

- 账面价值 > 计税基础（0）→ 可抵扣暂时性差异 → DTA

### 3.1.2 因未决诉讼确认的预计负债

分析逻辑与产品质量保证相同：
- 如果未来实际赔付时税法允许扣除 → 计税基础 = 0 → 可抵扣暂时性差异 → DTA
- 如果未来赔付属于罚款、罚金等税法不允许扣除的支出 → 计税基础 = 账面价值 → **无暂时性差异，不确认递延所得税**

> ⚠️ **考试陷阱**：不是所有预计负债都产生暂时性差异！关键要判断未来支出是否允许税前扣除。违反税法的罚款罚金，税法不允许扣除，自然不会有"未来可扣"的金额。

## 3.2 合同负债（预收账款）

### 3.2.1 税法与会计确认收入时点一致

- 会计上确认为合同负债，税法上也不要求提前纳税
- 计税基础 = 账面价值（未来可扣 = 0）
- **无暂时性差异**
### 3.2.2 税法与会计确认收入时点不一致

某些情况下，税法要求在收到预收款时即确认收入纳税（如房地产企业预售），而会计上确认为合同负债：
- 账面价值 = 预收金额
- 计税基础 = 账面价值 − 未来可扣金额 = 预收金额 − 预收金额 = 0
  （因为税法已经在收到时纳税，未来实际交付确认收入时，这部分不再重复纳税，相当于未来可以"扣除"）
- 账面 > 计税基础 → 可抵扣暂时性差异 → DTA

> 💡 **理解要点**：税法提前征税了，相当于你"多交"了，未来会"少交"回来，所以是DTA（未来可抵扣）。

## 3.3 应付职工薪酬

### 3.3.1 一般情况

企业为获得职工提供的服务而给予的各种形式的报酬，在会计上按权责发生制确认为负债和费用。税法规定，企业发生的合理的工资薪金支出准予据实扣除。

- 若年末应付职工薪酬已全部发放 → 账面价值 = 0 → 无差异
- 若年末存在未发放的应付职工薪酬 → 根据税法是否允许扣除判断

### 3.3.2 职工教育经费等有限额扣除的项目

| 项目 | 税法扣除限额 |
| :--- | :--- |
| 职工福利费 | 不超过工资薪金总额**14%** |
| 工会经费 | 不超过工资薪金总额**2%** |
| 职工教育经费 | 不超过工资薪金总额**8%**（超过部分准予在以后纳税年度结转扣除） |

- 超过限额且**不能结转扣除**的部分（如福利费、工会经费超限额）→ 永久性差异，不产生暂时性差异
- 超过限额但**可以结转扣除**的部分（如职工教育经费超限额）→ 可抵扣暂时性差异 → DTA

> [!example] 例题·计算分析题
> 甲企业2×24年12月计入成本费用的职工工资总额为**4 000**万元，至2×24年12月31日尚未支付。按照适用税法规定，当期计入成本费用的**4 000**万元工资支出中，可予税前扣除的合理部分为**3 000**万元。
>
> 该项应付职工薪酬于2×24年12月31日的账面价值为**4 000**万元。
>
> > [!check]- 答案与解析
> > **正确答案：**
> > ① 本期可予税前扣除的金额为**3 000**万元（本期纳税调增**1 000**万元）；
> > ② 未来可予税前扣除的金额为**0**；
> > ③ 计税基础 = 账面价值**4 000** - 未来可予抵扣的金额**0** = **4 000**万元；
> > ④ 账面价值**4 000**万元与其计税基础**4 000**万元相等，**不形成暂时性差异**。
> >
> > **甲企业2×24年有关所得税的会计处理：**
> > ① **应交所得税** = （利润总额 **+ 1 000**） × **25%**
> > ```
> > 借：所得税费用
> > 贷：应交税费——应交所得税
> > ```
> > ② **递延所得税（无）**
> >
> > **💡 易错点提示：**
> > 易将**永久差异**（当期及未来均不可扣除）误为**暂时性差异**（未来可扣除）。此处差异不逆转，故无暂时性差异、无递延所得税。

## 3.4 其他负债

### 3.4.1 罚款、滞纳金等

企业因违反法律法规确认的罚款、滞纳金等，税法规定不允许税前扣除。
- 计税基础 = 账面价值（未来可扣 = 0）
- **无暂时性差异**，属于**永久性差异**

### 3.4.2 附有销售退回条款的销售

企业确认的预计负债（预计退货部分），未来实际退货时可以冲减收入，税法在实际退货时才允许调整。
- 可能产生暂时性差异，需具体分析

# 4. 特殊项目产生的暂时性差异

## 4.1 未作为资产/负债确认但有计税基础的项目

某些项目，会计上未确认为资产或负债，但税法赋予了计税基础，也会产生暂时性差异。

**典型情形：广告费和业务宣传费**

税法规定，企业发生的符合条件的广告费和业务宣传费支出，不超过当年销售（营业）收入**15%** 的部分，准予扣除；超过部分，准予在以后纳税年度**结转扣除**。

- 超过限额的部分，当期不能扣除，但未来可以扣除
- 会计上已全额计入当期费用，未确认为资产
- 相当于一项"资产"的账面价值 = 0，计税基础 = 可结转扣除金额
- 账面 < 计税基础 → 可抵扣暂时性差异 → DTA

**典型情形：公益性捐赠支出**

税法规定，企业通过公益性社会组织等机构，用于慈善活动、公益事业的公益性捐赠支出，在年度利润总额12%以内的部分，准予在计算应纳税所得额时扣除；超过年度利润总额12%的部分，准予结转以后三年内在计算应纳税所得额时扣除。（ 产生可抵扣暂时性差异）
## 4.2 可抵扣亏损和税款抵减

企业发生的亏损，税法允许在**以后5年内**（高新技术企业和科技型中小企业为10年）用税前利润弥补。

- 可抵扣亏损本质上**等同于**可抵扣暂时性差异
- 在预计未来期间能够取得足够的应纳税所得额来弥补亏损的前提下，应确认DTA
- DTA = 可弥补亏损 × 适用税率

> ⚠️ **考试重点**：可抵扣亏损确认DTA的前提是"未来很可能取得足够的应纳税所得额"，如果企业持续亏损，可能不满足确认条件。

> [!example] 例题·计算分析题
> 甲公司于2×24年因政策性原因发生经营亏损**2 000**万元，按照税法规定，该亏损可用于抵减以后5个年度的应纳税所得额。该公司预计其于未来5年期间能够产生足够的应纳税所得额弥补该亏损。不考虑其他因素。
>
> （假定甲公司适用的所得税税率为**25%**）
>
> **要求：**
> 1. 列示甲公司2×24年有关所得税的会计处理。
> 2. 假定甲公司2×25年度实现利润总额**3 000**万元，无其他纳税调整事项，列示甲公司2×25年有关所得税的会计处理。
>
> > [!check]- 答案与解析
> > **正确答案：**
> >
> > **要求1：2×24年会计处理**
> >
> > **（1）确认递延所得税资产**
> > 可抵扣暂时性差异 = **2 000**万元
> > 递延所得税资产 = $2\,000 \times 25\% = 500$（万元）
> > 
> > ```
> > 借：递延所得税资产　　　　　　500
> > 　　贷：所得税费用　　　　　　500
> > ```
> >
> > **（2）应交所得税**
> > 当年发生亏损，应交所得税 = **0**（无需编制分录）
> >
> > ---
> >
> > **要求2：2×25年会计处理**
> >
> > **（1）转回递延所得税资产**
> > 本年弥补亏损**2 000**万元，转回递延所得税资产 = $2\,000 \times 25\% = 500$（万元）
> > 
> > ```
> > 借：所得税费用　　　　　　　　500
> > 　　贷：递延所得税资产　　　　500
> > ```
> >
> > **（2）计算并确认应交所得税**
> > 应纳税所得额 = 利润总额 - 可弥补亏损 = $3\,000 - 2\,000 = 1\,000$（万元）
> > 应交所得税 = $1\,000 \times 25\% = 250$（万元）
> > 
> > ```
> > 借：所得税费用　　　　　　　　　　250
> > 　　贷：应交税费——应交所得税　　250
> > ```
> >
> > **（3）2×25年所得税费用合计**
> > 所得税费用 = $500 + 250 = 750$（万元）
> >
> > ---
> >
> > **深度解析：**
> >
> > **第一步（理解2×24年亏损的税务处理）：**
> > - 会计上：亏损**2 000**万元形成**可抵扣暂时性差异**
> > - 税法上：当年无应纳税所得额，应交所得税为**0**
> > - 由于预计未来有足够利润弥补，确认**递延所得税资产** $2\,000 \times 25\% = 500$万元
> > - 递延所得税资产的确认**减少**当期所得税费用（贷方）
> >
> > **第二步（理解2×25年弥补亏损的处理）：**
> > - **税法计算**：应纳税所得额 = $3\,000 - 2\,000 = 1\,000$万元，应交所得税 = **250**万元
> > - **会计处理**：
> >   - 转回递延所得税资产**500**万元（借记所得税费用）
> >   - 确认当期应交所得税**250**万元（借记所得税费用）
> >   - 合计所得税费用 = $500 + 250 = 750$万元
> >
> > **第三步（验证会计等式）：**
> > 所得税费用**750**万元 = 利润总额**3 000**万元 × 税率**25%**
> > 验证正确！
> >
> > **💡 易错点提示：**
> > 1. **混淆应交所得税与所得税费用**：2×25年应交所得税是**250**万元（按税法扣除亏损后计算），但所得税费用是**750**万元（还需加上递延转回**500**万元）
> > 2. **计算顺序错误**：必须按税法规定**先用利润总额抵减可弥补亏损**（3 000 - 2 000），再乘以税率，不能直接用 $3\,000 \times 25\% - 500$
> > 3. **忽略递延转回**：弥补亏损时，之前确认的递延所得税资产必须转回，这会**增加**当期所得税费用
# 5. 递延所得税资产及负债的确认和计量

## 5.1 确认的一般原则

### 5.1.1 递延所得税负债的确认

除所得税准则中明确规定可不确认递延所得税负债的情况以外，企业对于所有的应纳税暂时性差异均应确认相关的递延所得税负债。

除与直接计入所有者权益的交易或事项以及企业合并中取得资产、负债相关的以外，在确认递延所得税负债的同时，应增加利润表中的所得税费用。

（1）确认应纳税暂时性差异产生的递延所得税负债时，交易或事项发生时影响到**会计利润**或**应纳税所得额**的，相关的所得税影响应作为利润表中**所得税费用**的组成部分；
```
借：所得税费用　　　　　　　　　   　 　　
　贷：递延所得税负债　
```

（2）与直接计入所有者权益的交易或事项相关的，其所得税影响应增加或减少所有者权益（**其他综合收益**、**其他权益工具**和**资本公积**等）；
```
借：其他综合收益
    其他权益工具
    资本公积
　贷：递延所得税负债　
```

（3）企业合并产生的，相关的递延所得税影响应调整购买日应确认的**商誉**或是计入**当期损益**的金额。
（以企业合并产生商誉为例）
```
借：商誉
　贷：递延所得税负债
```
### 5.1.2 递延所得税资产的确认

- 递延所得税资产产生于可抵扣暂时性差异。确认因可抵扣暂时性差异产生的递延所得税资产**应以未来期间可能取得的应纳税所得额为限**。
- 企业在进行所得税会计处理时，只有在确凿证据表明未来期间很可能获得足够的应纳税所得额用来抵扣暂时性差异时，才应当确认相关的递延所得税资产；而对于发生的相关应纳税暂时性差异，则应当及时足额确认递延所得税负债，这是会计信息**谨慎性要求**的具体体现。
## 5.2 不确认的特殊情况（3种）

有些情况下，虽然资产、负债的账面价值与其计税基础不同，产生了应纳税暂时性差异，但出于各方面考虑，所得税准则中规定不确认相应的递延所得税负债，主要包括：

### 5.2.1  **商誉的初始确认**

**非同一控制下**的企业合并中，企业合并成本大于合并中取得的被购买方可辨认净资产公允价值份额的差额，按照会计准则规定应确认为商誉。

因会计与税收的划分标准不同，会计上作为非同一控制下的企业合并，但如果按照税法规定计税时作为**免税合并**的情况下，**商誉的计税基础为0**，其账面价值与计税基础形成应纳税暂时性差异，但会计准则规定**不确认**与其相关的递延所得税负债。

| 问题           | 答案                                |
| ------------ | --------------------------------- |
| 免税合并是什么      | 税法允许暂不纳税，但资产计税基础沿用原值的特殊性税务处理      |
| 商誉计税基础为何为0   | 税法不承认商誉，多付的钱不分配计税基础               |
| 为何不确认递延所得税负债 | 确认会导致商誉金额循环调整，逻辑上无法自洽，属于准则明确规定的例外 |

> [!note]- 举例说明
> A公司花 **1亿元** 收购B公司 **100%股权**（非同一控制下企业合并）。
> 
> 收购日，B公司可辨认净资产的 **公允价值 = 8000万**，**账面价值也是8000万**（简化处理）。
> 
> 那会计上确认的商誉：
> $$商誉 = 1亿 - 8000万 = 2000万$$
> 
> 
>  **❖ 什么是免税合并？**
> 
> 税法把企业合并分两种：
> 
> | 类型 | 核心条件 | 税务处理 |
> | --- | --- | --- |
> | **应税合并** | 被合并方需要按公允价值清算，确认转让所得纳税 | 合并方取得资产按**公允价值**作为计税基础 |
> | **免税合并** | 股权支付比例≥85%，且有合理商业目的等（特殊性税务处理） | 被合并方暂不确认所得，合并方取得资产按**原账面价值**作为计税基础 |
> 
> 说白了，**免税合并就是税务局说：你们这次合并，先不收税，但代价是——你拿到的资产，计税基础只能沿用被合并方原来的账面价值，不能按公允价值重新计量。**
> 
> 这是典型的「延税」思路——现在不征，以后你处置资产的时候再算账。
> 
> ---
> **❖ 为什么免税合并下商誉的计税基础为0？**
> 
> 在免税合并中，**税法根本不承认「商誉」这个东西的存在**。
> 
> 税法的逻辑是这样的：
> - 你A公司花了1亿买B公司
> - 税法认为你拿到的东西就是B公司那堆可辨认净资产，计税基础沿用原值 = 8000万
> - 那你多付的2000万呢？**税法不管**。税法没有给商誉分配任何计税基础
> 
> 所以：
> 
> $$商誉的计税基础 = 0$$
> 
> $$暂时性差异 = 账面价值2000万 - 计税基础0 = 2000万（应纳税暂时性差异）$$
> 
> ---
>  **❖ 为什么有差异却不确认递延所得税负债？**
> 
> 这才是最精髓的地方。按理说，2000万的应纳税暂时性差异，税率25%，应该确认500万的递延所得税负债对吧？
> 
> **但如果你确认了，会发生什么？**
> 
> 假设确认递延所得税负债500万，非同一控制下企业合并中，这个递延所得税负债会**调增商誉**：
> 
> $$新商誉 = 2000万 + 500万 = 2500万$$
> 
> 但是！新商誉2500万，计税基础还是0，暂时性差异变成了2500万，对应的递延所得税负债应该是625万……
> 
> 然后商誉又要调成 2000 + 625 = 2625万……再算递延所得税负债又变了……
> 
> **你发现了吗？这是一个无限循环，永远收敛不了。**
> 
> 更本质地说，准则不让确认的原因是：
> 
> > **商誉本身就是合并对价与可辨认净资产公允价值的「差额」，它是个倒挤出来的数。如果因为商誉产生的暂时性差异去确认递延所得税，会反过来改变商誉的金额，导致逻辑上的「循环定义」，破坏了商誉计量的基础。**
> 
> 这就是准则明确规定的**例外情况**——即使存在应纳税暂时性差异，也**不确认**递延所得税负债。

|          | **可辨认资产和负债**                                    | **合并商誉**                              |
| -------- | ----------------------------------------------- | ------------------------------------- |
| 免税<br>合并 | 账面价值（公允价值）与计税基础（**被购买方原计税基础**）的差异，应确认递延所得税资产或负债 | 账面价值与计税基础的差异，不确认递延所得税负债<br>（商誉计税基础=0） |
| 应税<br>合并 | 账面价值（公允价值）=计税基础（公允价值），无暂时性差异                    | 账面价值=计税基础，<br>无暂时性差异                  |

应予说明的是，按照会计准则规定在非同一控制下企业合并中确认了商誉，并且按照所得税法规的规定该**商誉**在初始确认时**计税基础等于账面价值**的（如：应税合并），该商誉在**后续计量**过程中因会计准则规定与税法规定不同产生暂时性差异的（如商誉发生减值），应当确认相关的所得税影响。

### 5.2.2 **初始确认的豁免**

**同时具有下列特征**的交易中所产生的资产、负债的初始确认金额与其计税基础不同，形成暂时性差异的，交易发生时**不确认**相应的递延所得税负债/资产：

 ① 不是企业合并：
企业合并有自己的一套规则（你刚才看的商誉那块就是），所以这里先把合并排除掉，只讨论**日常交易**。

② 交易发生时既不影响会计利润也不影响应纳税所得额：
这是最关键的一个条件。意思是这笔交易**纯粹是资产负债表上的事**，没有碰损益表，也没有碰税法的应纳税所得额。

 ③ 未导致产生等额的应纳税和可抵扣暂时性差异：
这是2022年新加的条件，主要针对租赁等特殊业务（同时产生使用权资产和租赁负债，一个应纳税差异一个可抵扣差异，如果等额就不豁免了）。

 **为什么要豁免？** 关键在于：如果你非要确认DTL，借方该挂哪儿？

```
借：？？？
　贷：递延所得税负债
```

正常情况下借方挂**所得税费用**对吧？但条件②说了，这笔交易**不影响会计利润**，所以你不能挂所得税费用（×）。

那挂**商誉**？条件①说了不是企业合并，没有商誉可挂（打×）。

那只能挂**资产本身**了？比如你买了一台设备1000万，税法只认500万计税基础，差异500万。如果你确认DTL 125万（假设25%税率），借方挂到设备上，设备就变成1125万了。但问题来了——你实际花了1000万买的，现在账上变成1125万，这就**违反了历史成本原则**，会计信息不可靠了。

所以准则说：**算了，这种情况干脆别确认了。**

> 这个豁免的本质就是：**当递延所得税的借方找不到合理的归属科目时，与其扭曲会计信息，不如不确认。**

> [!example]  最典型的例子---一个不涉及企业合并的**免税交易**中取得资产：
> 比如你花1000万买了一项资产，但税法规定这笔交易免税，计税基础按0算。
> 
> - 账面价值 = 1000万
> - 计税基础 = 0
> - 应纳税暂时性差异 = 1000万
> 
> 但这笔交易：不是合并（✓），不影响利润也不影响应纳税所得额（✓），没有等额反向差异（✓），三个条件全满足 → **不确认DTL**。

> [!example] 例题·知识点解析
> A公司进行内部研究开发所形成的无形资产成本为 $1\,200$ 万元，因按照税法规定可于未来期间税前扣除的金额为 $2\,400$ 万元（$1\,200 \times 200\%$），其计税基础为 $2\,400$ 万元。
>
> **问题：** 该无形资产账面价值与计税基础之间的暂时性差异，是否应确认递延所得税资产？若确认，应贷记什么科目？
>
> > [!check]- 答案与解析
> > 
> > **正确答案：不确认递延所得税资产**
> >
> > **深度解析：**
> >
> > **第一步：确认暂时性差异**
> > - 账面价值 = $1\,200$ 万元
> > - 计税基础 = $2\,400$ 万元（$1\,200 \times 200\%$）
> > - 账面价值 **<** 计税基础，产生**可抵扣暂时性差异** = $2\,400 - 1\,200 = 1\,200$ 万元
> >
> > **第二步：判断是否满足"初始确认豁免"条件**
> > 该项无形资产同时满足以下**三个条件**，触发初始确认豁免：
> > 1. **并非产生于企业合并**（内部研发形成）
> > 2. **初始确认时既不影响会计利润也不影响应纳税所得额**（资本化时借记无形资产，不涉及损益）
> > 3. **初始确认的资产未导致产生等额的应纳税暂时性差异和可抵扣暂时性差异**
> >
> > **第三步：分析贷方科目的不可行性**
> > 若强行确认递延所得税资产，贷方无合理科目对应：
> >
> > | 假设贷方科目 | 结论 |
> > |---|---|
> > | 所得税费用 | ✘ 初始确认时不影响损益 |
> > | 商誉 | ✘ 非企业合并，不存在商誉 |
> > | 其他综合收益 | ✘ 该交易与其他综合收益无关 |
> > | 无形资产 | ✘ 调整入账价值违背**历史成本原则**，影响会计信息可靠性 |
> >
> > **结论：** 所得税准则规定，该种情况下**不确认**相关的递延所得税资产。
> >
> > **💡 易错点提示：**
> > ① 内部研发形成的无形资产加计扣除产生的暂时性差异，属于经典的"**初始确认豁免**"情形，在**整个持有期间**均不确认递延所得税，而非仅在初始确认时不确认。
> > ② 注意与"企业合并中取得的无形资产"区分——企业合并中产生的暂时性差异**不适用**初始确认豁免，需正常确认递延所得税（对应科目为商誉）。
### 5.2.3 与**长期股权投资**相关的应纳税暂时性差异

与长期股权投资相关的**应纳税**暂时性差异，**同时满足**以下两个条件时，投资企业**无须确认**相应的递延所得税负债：

- ①投资企业**能够控制暂时性差异转回的时间**；
- ②该暂时性差异在可预见的未来**很可能不会转回**。

满足上述条件时，投资企业可以运用自身的影响力决定暂时性差异的转回，如果不希望其转回，则在可预见的未来期间，该项暂时性差异不会转回，对未来期间计税不产生影响，从而无须确认相应的递延所得税负债。

对于采用**权益法核算**的长期股权投资，其账面价值与计税基础产生的暂时性差异是否应确认相关的所得税影响，**应考虑该项投资的持有意图**

> 💡 **通俗理解**：母公司投资子公司，子公司赚了钱导致长投账面价值增加（权益法下），产生了应纳税暂时性差异。但只要母公司不打算卖掉子公司或让子公司分红，这个差异就不会转回，所以不用确认DTL。

> [!example] 例题·多选题
> 甲公司持有乙公司30%股权，按权益法核算对乙公司的股权投资，原计划长期持有。2×22年12月31日，甲公司管理层决定近期以3 000万元的价格出售所持有的乙公司股权。当日，甲公司对乙公司长期股权投资账面价值为2 200万元，其中，初始投资成本为600万元，损益调整为1 200万元，其他权益变动为400万元。根据企业所得税税法规定，计算股权转让所得时，转让股权收入仅应扣除为取得该股权所发生的成本。甲公司适用的企业所得税税率为25%。不考虑其他因素，下列各项关于甲公司2×22年12月31日所得税会计处理的表述中，正确的有（    ）。
> A. 确认递延所得税负债400万元
> B. 冲减长期股权投资300万元
> C. 确认所得税费用400万元
> D. 冲减资本公积100万元
>
> > [!check]- 答案与解析
> > 
> > **正确答案：AD**
> >
> > **深度解析：**
> >
> > **第一步：判断是否需要确认递延所得税**
> > 原计划长期持有时，权益法下因损益调整和其他权益变动产生的暂时性差异，满足长期持有条件（投资方能够控制暂时性差异转回的时间且该暂时性差异在可预见的未来很可能不会转回），**无需确认递延所得税**。但2×22年12月31日管理层决定近期出售，**长期持有意图不再成立**，暂时性差异预期将会转回，应当确认递延所得税。
> >
> > **第二步：计算暂时性差异**
> > - 账面价值 = **2 200万元**
> > - 计税基础 = 初始投资成本 = **600万元**（税法仅允许扣除取得股权的成本）
> > - 应纳税暂时性差异 = $2\ 200 - 600 = 1\ 600$（万元）
> >
> > **第三步：计算递延所得税负债**
> > $$递延所得税负债 = 1\ 600 \times 25\% = 400 \text{（万元）}$$
> > **→ 选项A正确** ✅
> >
> > **第四步：分析递延所得税负债的对应科目**
> > 暂时性差异 **1 600万元** 由两部分构成：
> > - **损益调整 1 200万元** → 对应递延所得税费用 = $1\ 200 \times 25\% = 300$（万元），计入**所得税费用**
> > - **其他权益变动 400万元** → 对应递延所得税 = $400 \times 25\% = 100$（万元），计入**资本公积—其他资本公积**
> >
> > 会计分录：
> > > 借：所得税费用　　　　　　　　300
> > > 　　资本公积—其他资本公积　　100
> > > 　贷：递延所得税负债　　　　　　400
> >
> > **→ 选项B错误** ❌（不涉及冲减长期股权投资）
> > **→ 选项C错误** ❌（所得税费用为 **300万元**，非400万元）
> > **→ 选项D正确** ✅（冲减资本公积100万元）
> >
> > **💡 易错点提示：**
> > ① 权益法下长期股权投资的暂时性差异，**只有在不再满足"长期持有"条件时**才需确认递延所得税，这是本题的前提判断关键。
> > ② 递延所得税的对应科目应遵循"**追溯产生根源**"原则：损益调整产生的差异对应所得税费用，其他权益变动产生的差异对应资本公积，**不能全部计入所得税费用**，这是选项C的陷阱所在。
## 5.3 递延所得税的计量
 
 1. 递延所得税负债的计量

- 递延所得税负债应以相关应纳税暂时性差异**转回期间**按照税法规定适用的所得税税率计量。
- 无论应纳税暂时性差异何时转回，相关的递延所得税负债**不要求折现**。
 
 2. 递延所得税资产的计量

- 确认递延所得税资产时，应当以**预期收回该资产期间**的适用所得税税率为基础计算确定。
- 无论相关的可抵扣暂时性差异何时转回，递延所得税资产均**不要求折现**。

## 5.4 特殊交易或事项中涉及递延所得税的确认和计量

### 5.3.1 与直接计入所有者权益的交易或事项相关的所得税

与当期及以前期间直接计入所有者权益的交易或事项相关的当期所得税及递延所得税应当计入所有者权益。直接计入所有者权益的交易或事项主要有：

（1）**会计政策变更**采用追溯调整法或对**前期差错更正**采用追溯重述法调整**期初留存收益**。
```
（以涉及递延所得税资产为例）
借：递延所得税资产
　贷：利润分配——未分配利润

（以涉及递延所得税资产为例）
借：递延所得税资产
　贷：以前年度损益调整
```

（2）以公允价值计量且其变动计入**其他综合收益**的金融资产公允价值的变动金额。
```
借：递延所得税资产
　贷：其他综合收益
```

（3）同时包含负债及权益成分的金融工具在初始确认时计入**所有者权益**。
```
借：其他权益工具
　贷：递延所得税负债
```

> [!note]
> 会计准则规定，企业发行的可转换公司债券，应当在初始确认时将其包含的负债成分和权益成分进行分拆，将负债成分确认为应付债券，将权益成分确认为**其他权益工具**。其中对于负债成分，企业应在资产负债表日按应付债券的摊余成本和实际利率计算确定债券的利息费用。
> 
> 税法规定，发行方企业发生的可转换债券的利息，按照规定在税前扣除。（假定该利息应根据债券票面本金和票面利率计算确定）
> 
> 可转换债券初始确认时，**负债成分的计税基础等于负债成分与权益成分的初始账面金额之和**，如果负债成分的计税基础与负债成分的账面价值不相等，则形成暂时性差异，由于该差异是由初始确认时单独确认的权益成分所导致，所以该暂时性差异在符合会计准则规定的确认条件时，应将所得税的影响金额确认递延所得税负债或资产，并计入**其他权益工具**。


（4）自用房地产转为采用公允价值模式计量的投资性房地产时公允价值大于原账面价值的差额计入**其他综合收益**等。
```
借：投资性房地产——成本
　　累计折旧
　贷：固定资产
　　　其他综合收益
借：其他综合收益
　贷：递延所得税负债
```

### 5.3.2 与企业合并相关的递延所得税

在企业合并中，购买方取得的可抵扣暂时性差异，比如，购买日取得的被购买方在以前期间发生的未弥补亏损等可抵扣暂时性差异，按照税法规定可以用于抵减以后年度应纳税所得额，但在**购买日**如果不符合递延所得税资产确认条件则不予以确认。

**购买日后**，如果预期被购买方在购买日可抵扣暂时性差异带来的经济利益能够实现的，购买方应区分以下两种情形，确认相关的递延所得税资产：

| **情形**                                                                           | **会计处理**                                                                                       |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1.**购买日后12个月内**，如果取得了新的或进一步的信息表明，**购买日的相关情况已经存在**，预期被购买方在购买日可抵扣暂时性差异带来的经济利益能够实现  | 应当确认相关的递延所得税资产，同时减少商誉，商誉不足冲减的，差额部分确认为当期损益。<br><br>借：递延所得税资产<br>　贷：商誉<br>　　　所得税费用（商誉不足冲减时的差额部分） |
| 2.除上述情况以外：<br><br>**①购买日后超过12个月；**<br>**或**<br>**②** **购买日并不存在相关情况而是在购买日以后开始出现** | 如果符合递延所得税资产的确认条件，应当确认与企业合并相关的递延所得税资产，计入当期损益（所得税费用），**不得调整商誉金额**。<br><br>借：递延所得税资产<br>　贷：所得税费用  |

> [!example] 例题·单选题（2022）
> 2×20年5月1日，甲公司从独立第三方收购了乙公司60%的股权并取得控制权，确认商誉**800万元**。购买日，乙公司存在历史期间尚可在税前抵扣的未弥补亏损**500万元**，因不符合确认条件而未确认递延所得税资产。2×21年2月1日，在甲公司的支持下，乙公司开展了新的业务，乙公司基于调整后的新业务预计未来期间能够产生足够的应纳税所得额用以抵减可抵扣暂时性差异，因此，乙公司于2×21年2月末确认了递延所得税资产，同时冲减所得税费用。
>
> 不考虑其他因素，甲公司在2×21年度合并乙公司财务报表时，下列各项有关所得税的抵销或调整的表述中，正确的是（　　）。
>
> A. 无需抵销或调整
> B. 调整所得税费用和商誉
> C. 调整所得税费用和资本公积
> D. 调整所得税费用和年初未分配利润
>
> > [!check]- 答案与解析
> > 
> > **正确答案：A**
> >
> > **深度解析：**
> >
> > **关键判断：确认递延所得税资产的时点及原因**
> >
> > **第一步：明确购买日的情况**
> > - 购买日（2×20年5月1日），乙公司未弥补亏损**500万元**因**不符合确认条件**而未确认递延所得税资产。
> > - 此时确认的商誉为**800万元**，已反映了未确认递延所得税资产的影响。
> >
> > **第二步：分析购买日后确认递延所得税资产的原因**
> > - 2×21年2月，乙公司确认递延所得税资产的原因是**开展了新业务**，基于新业务预计未来能产生足够的应纳税所得额。
> > - 这属于**购买日后发生的新事项（新业务）**导致的变化，**不属于**购买日已存在但在计量期间内取得了新信息的情形。
> >
> > **第三步：判断是否需要调整商誉**
> > - 根据准则规定，只有在**购买日后12个月的计量期内**，因取得了**购买日已存在情况的新信息**而确认递延所得税资产的，才需要调减商誉（商誉不够冲减的，差额确认为当期损益）。
> > - 本题中，乙公司确认递延所得税资产的原因是**购买日后新开展的业务**，而非购买日已存在情况的新证据，因此**不属于计量期调整事项**，无需调整商誉。
> >
> > **第四步：合并报表层面的处理**
> > - 乙公司在其个别报表中确认递延所得税资产并冲减所得税费用，该处理本身是正确的。
> > - 在合并层面，由于不涉及计量期调整，也不涉及内部交易抵销等问题，**无需进行额外的抵销或调整**。
> >
> > **💡 易错点提示：**
> > 本题极易误选**B（调整所得税费用和商誉）**。关键区分点在于：确认递延所得税资产的原因是**"购买日后的新事项"（新业务）**还是**"购买日已存在情况的新信息"**。只有后者才在计量期内调整商誉。本题明确指出是因"新业务"导致预计未来有足够应纳税所得额，属于购买日后的新变化，故不调整商誉，合并层面无需抵销或调整。

### 5.3.3 与股份支付相关的当期及递延所得税

与股份支付相关的支出在按照会计准则规定确认为成本费用时，其相关的所得税影响应区别于税法的规定进行处理：

1.如果税法规定与股份支付相关的支出**不允许税前扣除**，则不形成暂时性差异。

```
（以权益结算股份支付为例）
借：管理费用等　　　　　　　
　贷：资本公积——其他资本公积
```

计算应交所得税时纳税调增；不影响递延所得税。

2.如果税法规定与股份支付相关的支出**允许税前扣除**，在按照会计准则规定确认成本费用的期间内，企业应当根据会计期末取得的信息估计可税前扣除的金额计算确定其计税基础及由此产生的暂时性差异，符合确认条件的情况下，应当确认相关的递延所得税。

（1）税法规定 **（以股票期权为例，假定授予日权益工具的公允价值为18元，行权价格为5元）**

根据税法规定，对于附有业绩条件或服务条件的股权激励计划，企业按照会计准则的相关规定确认的成本费用 **（18元）在等待期内不得税前抵扣**，待股权激励计划**可行权时方可抵扣**，可抵扣的金额为**实际行权时的股票公允价值（20元）** 与**激励对象支付的行权金额（5元）** 之间的差额。因此，企业未来可抵扣的金额 **（15元）** 与等待期内确认的成本费用金额 **（18元）** 很可能存在差异。

- 会计准则确认的成本费用=授予日权益工具的公允价值（18元）
- 税法未来可抵扣的金额=实际行权时股票的公允价值（20元）/（26元）-激励对象支付的行权金额（5元）
- 【提示】站在税法角度，认为上述差额才是企业股权激励成本。

（2）会计处理

①如果**预计未来期间可抵扣的金额[15元（20-5）]** 未超过**等待期内确认的股权激励费用（18元）**，企业应根据**期末的股票价格（20元）** 估计未来可以税前抵扣的金额**15元（20-5）**，以未来期间很可能取得的应纳税所得额为限确认递延所得税资产。
```
（未来可抵扣的金额≤会计准则确认的激励费用）
借：递延所得税资产 （未来可抵扣的金额15元×25%）
　贷：所得税费用　　　（15元×25%）
```

还有3元（18-15）理解为超标部分，不可税前扣除。

②如果**预计未来期间可抵扣的金额[21元（26-5）]** 超过**等待期内确认的股权激励费用（18元）**，超出部分 **[3元（21-18）]** 形成的递延所得税资产应直接计入**所有者权益（资本公积——其他资本公积）**。
```
（未来可抵扣的金额＞会计准则确认的激励费用）
借：递延所得税资产（未来可抵扣的金额21元×25%）
　贷：所得税费用（会计准则确认的激励费用18元×25%）
　　　资本公积——其他资本公积　　　　（差额）
```

> [!example] 例题·计算分析题
> 甲公司于2×24年1月1日授予1名管理人员1 000股限制性股票激励计划（每股面值为1元），服务期限条件为2年，甲公司预计1 000股限制性股票在2年后均可行权。限制性股票的授予价格为10元/股，甲公司股票在授予日的市场价格为19元/股。经测算，限制性股票在授予日的公允价值为9元/股。假定甲公司满足确认递延所得税资产的条件，适用的所得税税率为25%。假设甲公司股票在2×24年12月31日及2×25年12月31日的市场价格分别17元/股和22元/股。
>
> **要求：** 编制甲公司2×24年1月1日授予限制性股票、2×24年12月31日及2×25年12月31日确认股份支付费用及递延所得税的相关会计分录。
>
> > [!check]- 答案与解析
> >
> > ---
> > **① 2×24年1月1日，甲公司授予限制性股票**
> >
> > 收到认购款：
> > $$借：银行存款 \quad (1\ 000 \times 10) \quad 10\ 000$$
> > $$\quad 贷：股本 \quad 1\ 000$$
> > $$\quad \quad \quad 资本公积——股本溢价 \quad 9\ 000$$
> >
> > 同时，将收到的认购款作为限制性股票的回购义务：
> > $$借：库存股 \quad 10\ 000$$
> > $$\quad 贷：其他应付款 \quad 10\ 000$$
> >
> > ---
> > **② 2×24年12月31日，确认股份支付费用及递延所得税**
> >
> > **第一步：确认当期股份支付费用**
> >
> > 等待期内累计应确认费用 $= 1\ 000 \times \mathbf{9} \times \dfrac{12}{24} = 4\ 500$（元）
> >
> > $$借：管理费用 \quad 4\ 500$$
> > $$\quad 贷：资本公积——其他资本公积 \quad 4\ 500$$
> >
> > **第二步：计算预计未来可税前抵扣金额**
> >
> > 甲公司股票2×24年12月31日市价为 **17元/股**，预计未来可税前抵扣金额：
> > $$(17 - \mathbf{10}) \times 1\ 000 = 7\ 000 \text{（元）}$$
> >
> > 等待期内应确认的股份支付费用总额 $= \mathbf{9} \times 1\ 000 = 9\ 000$（元）
> >
> > 因 $7\ 000 < 9\ 000$，预计可抵扣金额 **小于** 费用总额，递延所得税资产全部计入 **所得税费用**。
> >
> > **第三步：确认递延所得税资产**
> >
> > 按可抵扣金额在等待期内的累计分摊额确认：
> > $$\left[(17 - 10) \times 1\ 000 \times \frac{12}{24}\right] \times 25\% = \mathbf{3\ 500} \times 25\% = 875 \text{（元）}$$
> >
> > $$借：递延所得税资产 \quad 875$$
> > $$\quad 贷：所得税费用 \quad 875$$
> >
> > **第四步：确认当期应交所得税**
> >
> > 纳税调整：当期会计确认费用 **4 500元** 不可税前扣除（需调增），同时可抵扣暂时性差异对应的 **3 500元** 也需调增（尚未实际抵扣）：
> > $$应交所得税 = (利润总额 + 3\ 500 + 1\ 000) \times 25\%$$
> >
> > $$借：所得税费用$$
> > $$\quad 贷：应交税费——应交所得税$$
> >
> > ---
> > **③ 2×25年12月31日，确认股份支付费用及递延所得税**
> >
> > **第一步：确认当期股份支付费用**
> >
> > 累计应确认费用 $= 1\ 000 \times 9 = 9\ 000$（元），当期应确认 $= 9\ 000 - 4\ 500 = 4\ 500$（元）
> >
> > $$借：管理费用 \quad 4\ 500$$
> > $$\quad 贷：资本公积——其他资本公积 \quad 4\ 500$$
> >
> > **第二步：计算预计未来可税前抵扣金额**
> >
> > 甲公司股票2×25年12月31日市价为 **22元/股**，预计未来可税前抵扣金额：
> > $$(\mathbf{22 - 10}) \times 1\ 000 = 12\ 000 \text{（元）}$$
> >
> > 等待期内股份支付费用总额 $= 9\ 000$（元）
> >
> > 因 $12\ 000 > 9\ 000$，预计可抵扣金额 **大于** 费用总额，超出部分 $= 12\ 000 - 9\ 000 = \mathbf{3\ 000}$（元）形成的递延所得税资产应直接计入 **所有者权益（资本公积）**。
> >
> > **第三步：确认递延所得税资产**
> >
> > | 项目 | 金额 |
> > |---|---|
> > | 递延所得税资产累计余额 | $12\ 000 \times 25\% = 3\ 000$（元） |
> > | 已确认余额 | $875$（元） |
> > | **本期应增加** | $3\ 000 - 875 = \mathbf{2\ 125}$（元） |
> >
> > 其中：
> > - 计入 **所得税费用** $= 9\ 000 \times 25\% - 875 = \mathbf{1\ 375}$（元）
> > - 计入 **资本公积——其他资本公积** $= 3\ 000 \times 25\% = \mathbf{750}$（元）
> >
> > $$借：递延所得税资产 \quad 2\ 125$$
> > $$\quad 贷：所得税费用 \quad 1\ 375$$
> > $$\quad \quad \quad 资本公积——其他资本公积 \quad 750$$
> >
> > ---
> >
> > **💡 易错点提示：**
> > 1. 限制性股票的**行权价格 = 授予价格**（本题为10元/股），计算可抵扣金额时用 **市价 − 授予价格**，而非市价 − 公允价值。
> > 2. 预计可抵扣金额与费用总额的**大小比较**决定了递延所得税资产的贷方科目：未超出部分→**所得税费用**；超出部分→**资本公积（所有者权益）**。
> > 3. 等待期内递延所得税资产的确认需按**累计分摊比例**计算（如第一年 $\frac{12}{24}$），而非一次性全额确认。

> [!example] 例题·多选题（2021）
> 在未来期间能够产生足够的应纳税所得额用以抵减可抵扣暂时性差异并不考虑其他因素的情况下，下列各项交易或事项涉及所得税会计处理的表述中正确的有（    ）。

> A. 内部研发形成的无形资产，初始入账金额与计税基础之间的差异应确认递延所得税并计入当期损益
> B. 股份支付产生的暂时性差异，如果预计未来期间可抵扣的金额超过等待期内确认的成本费用，超出部分形成的递延所得税应计入所有者权益
> C. 以公允价值计量且其变动计入其他综合收益的非交易性权益工具投资的公允价值变动产生的暂时性差异应确认递延所得税并计入其他综合收益
> D. 企业发行可转换公司债券，初始入账金额与计税基础之间的差异应确认递延所得税并计入当期损益
>
> > [!check]- 答案与解析
> > 
> > **正确答案：BC**
> >
> > **深度解析：**
> >
> > **选项A（×）：** 内部研发形成的无形资产，按税法规定可按 $175\%$（加计扣除）确认计税基础，导致计税基础 > 账面价值，产生**可抵扣暂时性差异**。但该差异属于**"初始确认豁免"**情形——该交易既不是企业合并，也不影响会计利润和应纳税所得额，因此**不确认递延所得税**。
> >
> > **选项B（✓）：** 股份支付等待期内确认的成本费用形成可抵扣暂时性差异，正常部分对应的递延所得税计入**当期损益**。但如果预计未来可税前抵扣的金额**超过**等待期内累计确认的成本费用，**超出部分**形成的递延所得税应直接计入**所有者权益（资本公积）**，体现了"来源一致"原则。
> >
> > **选项C（✓）：** 以公允价值计量且其变动计入其他综合收益的非交易性权益工具投资（即**其他权益工具投资**），其公允价值变动计入**其他综合收益**，由此产生的暂时性差异确认的递延所得税也应计入**其他综合收益**，遵循"所得税费用的确认应与产生该差异的交易或事项的确认方式一致"原则。
> >
> > **选项D（×）：** 企业发行可转换公司债券，会计上将其拆分为**负债成分**和**权益成分**，而税法上将其整体作为负债处理，因此产生暂时性差异。该差异确认的递延所得税在初始确认时应计入**所有者权益（资本公积）**，而非当期损益，因为权益成分本身就计入了所有者权益。
> >
> > **💡 易错点提示：**
> > 递延所得税的对应科目遵循**"来源一致"原则**：产生暂时性差异的交易计入损益→递延所得税计入损益；计入其他综合收益→递延所得税计入其他综合收益；计入所有者权益→递延所得税计入所有者权益。选项A的核心陷阱在于**初始确认豁免**，选项D的陷阱在于可转债权益成分对应的递延所得税应计入**权益**而非损益。

### 5.3.4 与单项交易相关的递延所得税

对于不是企业合并、交易发生时既不影响会计利润也不影响应纳税所得额（或可抵扣亏损）、且**初始确认的资产和负债导致产生等额应纳税暂时性差异和可抵扣暂时性差异**的单项交易，**不适用**所得税准则中关于**豁免初始确认**递延所得税负债和递延所得税资产的规定。

企业对该单项交易因资产和负债的初始确认所产生的应纳税暂时性差异和可抵扣暂时性差异，应当在交易发生时**分别确认**相应的递延所得税负债和递延所得税资产。

### 5.3.5 发行方分类为权益工具的金融工具相关股利的所得税影响

1.永续债的所得税政策（税法规定）

根据《关于永续债企业所得税政策问题的公告》（财政部 税务总局 公告2019年第64号）的相关规定：

（1）企业发行的永续债，**可以适用股息、红利企业所得税政策**，即：投资方取得的永续债利息收入属于股息、红利性质，按照现行企业所得税政策相关规定进行处理，其中，发行方和投资方均为居民企业的，永续债利息收入可以适用企业所得税法规定的居民企业之间的股息、红利等权益性投资收益免征企业所得税规定；同时发行方支付的永续债利息支出**不得在企业所得税税前扣除**。**（发行方依法纳税；投资方税前扣除）**

（2）企业发行符合规定条件的永续债，**也可以按照债券利息适用企业所得税政策**，即：发行方支付的永续债利息支出**准予在其企业所得税税前扣除**；投资方取得的永续债利息收入应当依法纳税。**（发行方税前扣除；投资方依法纳税）**

| **发行方税务处理的选择**                 | **发行方的税务处理**                     | **投资方的税务处理**                                |
| ------------------------------ | -------------------------------- | ------------------------------------------- |
| （1）适用**股息、红利**企业所得税政策          | 发行方支付的永续债利息支出不得税前扣除<br>（相当于利润分配） | 投资方取得的**股息、红利**等权益性投资收益免征企业所得税<br>（相当于投资收益） |
| （2）按照**债券利息**适用企业所得税政策（符合规定条件） | 支付的永续债**利息支出**准予税前扣除（财务费用——利息支出） | 投资方取得的永续债**利息收入**应当依法纳税（财务费用——利息收入）         |

2.永续债**发行方**的所得税会计处理

对于企业（指发行方）按照金融工具列报准则等规定分类为权益工具的金融工具（如分类为权益工具的永续债等），但相关股利支出按照税收政策相关规定在企业所得税**税前扣除**的，企业应当在确认应付股利时，确认与股利相关的所得税影响。**（会计分类为“股”；税法选择为“债”）**

由于该股利的所得税影响通常与过去产生可供分配利润的交易或事项更为直接相关，企业应当按照与**过去产生可供分配利润的交易或事项**时所采用的会计处理相一致的方式，将股利的所得税影响计入当期损益或**所有者权益项目**（含其他综合收益项目）。

- ①对于所分配的利润来源于以前产生损益的交易或事项，该股利的所得税影响应当计入**当期损益**；
- ②对于所分配的利润来源于以前确认在所有者权益中的交易或事项，该股利的所得税影响应当计入**所有者权益**项目。

> [!example] 例题·多选题
> 2×24年4月1日，甲公司按面值发行永续债募集资金5 000万元，票面年利率为3.8%，支付发行费用1000万元，该永续债符合权益工具的定义。2×25年3月31日，甲公司根据本年实现的净利润拟进行股利分配，并从本年实现的净利润中向永续债持有人先行支付了利息。根据企业所得税法规定，该永续债的利息支出可以在当期税前扣除。不考虑企业所得税以外的相关税费及其他因素，下列各项关于甲公司永续债会计处理的表述中，正确的有（    ）。
>
> A. 将发行的永续债确认为其他权益工具
> B. 将支付永续债利息的所得税影响计入当期损益
> C. 将支付的发行费用冲减所有者权益
> D. 将支付的永续债利息计入当期损益
>
> > [!check]- 答案与解析
> > 
> > **正确答案：ABC**
> >
> > **深度解析：**
> > 
> > **第一步：明确永续债的会计分类**
> > 题目明确指出"该永续债**符合权益工具的定义**"，因此应确认为**其他权益工具**，而非金融负债。选项**A正确**。
> > 
> > **第二步：发行费用的处理**
> > 权益工具发行费用应**冲减权益（资本公积——股本溢价）**，不计入当期损益。
> > 会计分录：
> > ```
> > 借：银行存款 5 000
> >     资本公积——股本溢价 1 000
> >   贷：其他权益工具 6 000
> > ```
> > 选项**C正确**。
> > 
> > **第三步：永续债利息的会计处理**
> > 因永续债属于**权益工具**，向持有人支付的利息实质上是**利润分配**，应：
> > - **冲减未分配利润**（或盈余公积）
> > - **不计入当期损益**
> > 
> > 会计分录：
> > ```
> > 借：利润分配——应付永续债利息 190（5 000×3.8%）
> >   贷：应付股息 190
> > ```
> > 选项**D错误**。
> > 
> > **第四步：所得税影响的处理**
> > 虽然会计上将利息作为**利润分配**处理，但税法允许**税前扣除**，产生**可抵扣暂时性差异**：
> > - 计税基础 = $5000 - 190 = 4810$（万元）
> > - 账面价值 = $5000$（万元）
> > - 可抵扣暂时性差异 = $190$（万元）
> > 
> > 应确认递延所得税资产，所得税影响计入**当期所得税费用**（损益类科目）。
> > 会计分录：
> > ```
> > 借：递延所得税资产 47.5（190×25%）
> >   贷：所得税费用 47.5
> > ```
> > 选项**B正确**。
> >
> > **💡 易错点提示：**
> > - **陷阱在D选项**：容易误认为支付利息应计入"财务费用"或"利息费用"，但权益工具的利息支付本质是**股利分配**，应冲减所有者权益，不影响损益。
> > - **会税差异关键**：会计上作为权益处理，税法上允许扣除，形成暂时性差异需确认递延所得税资产。

## 5.5 适用税率变化对已确认递延所得税资产和递延所得税负债的影响

因税收法规的变化，导致企业在某一会计期间适用的**所得税税率发生变化**的，企业应对已确认的递延所得税资产和递延所得税负债按照新的税率进行重新计量。适用税率变动的情况下，应对原已确认的递延所得税资产及递延所得税负债的金额进行调整，反映税率变化带来的影响。

除直接计入所有者权益的交易或事项产生的递延所得税资产及递延所得税负债，相关的调整金额应计入所有者权益以外，其他情况下因税率变化产生的调整金额应确认为税率变化当期的**所得税费用（或收益）**。

> [!note]- 理解
> 第1步：重新计量
> 拿着你资产负债表上现有的暂时性差异金额，用新税率重新算：
> - **递延所得税资产** = 可抵扣暂时性差异 × 新税率
> - **递延所得税负债** = 应纳税暂时性差异 × 新税率
>  
>  第2步：算差额
> 新算出来的金额 - 原账面金额 = 需要调整的金额
> 
>  第3步：做分录
> 这里分两种情况：
> 
> **情况1：原来就是走损益的（大部分情况）**
> ```
> 借：递延所得税资产（如果增加）
>     所得税费用（如果递延所得税资产减少或负债增加）
> 贷：递延所得税负债（如果增加）
>     所得税费用（如果递延所得税负债减少或资产增加）
> ```
> 
> **情况2：原来是走权益的（比如其他综合收益）**
> 调整额也走权益科目，不影响当期损益。
> 
>  举个例子，假设你有个可抵扣暂时性差异100万：
> 
> **原来税率25%时：**
> - 递延所得税资产 = 100万 × 25% = 25万
> 
> **现在税率降到20%：**
> - 重新计量：100万 × 20% = 20万
> - 需要调减：25万 - 20万 = 5万
> 
> **分录：**
> ```
> 借：所得税费用  5万
> 贷：递延所得税资产  5万
> ```
> 

# 6. 所得税费用的确认和计量

## 6.1 当期所得税

$\text{当期所得税} = \text{应纳税所得额} \times \text{适用税率}$

**应纳税所得额的计算（间接法）：**

$\text{应纳税所得额} = \text{会计利润} + \text{纳税调增} - \text{纳税调减}$

**常见纳税调整项目：**

| 调整方向 | 项目 | 原因 |
| :--- | :--- | :--- |
| **调增** | 计提的资产减值准备 | 税法不认可，实际损失时才扣 |
| **调增** | 超标的业务招待费、广告费 | 税法有扣除限额 |
| **调增** | 税收罚款、滞纳金 | 税法不允许扣除 |
| **调增** | 公允价值下降（交易性金融资产） | 税法不认可公允价值变动损失 |
| **调减** | 国债利息收入 | 税法规定免税 |
| **调减** | 公允价值上升（交易性金融资产） | 税法不认可公允价值变动收益 |
| **调减** | 研发费用加计扣除 | 税法优惠 |
| **调减** | 权益法确认的投资收益（符合免税条件） | 居民企业间股息红利免税 |
## 6.2 递延所得税费用

$\text{递延所得税费用} = \Delta DTL - \Delta DTA$

> ⚠️ **重要限定**：这里的ΔDTL和ΔDTA仅指**对应所得税费用**的部分。以下情形产生的递延所得税**不计入所得税费用**：

| 对应科目 | 情形 |
| :--- | :--- |
| **其他综合收益** | 其他权益工具投资公允价值变动、重新计量设定受益计划净负债/净资产的变动等 |
| **商誉**（或调整合并成本） | 非同一控制下企业合并中取得资产/负债确认的递延所得税 |
| **所有者权益（资本公积）** | 与直接计入所有者权益的交易相关的递延所得税 |
## 6.3 所得税费用的计算

$\boxed{\text{所得税费用} = \text{当期所得税} + \text{递延所得税费用}}$

其中：
$\text{递延所得税费用} = （期末DTL - 期初DTL）_{计入损益部分} - （期末DTA - 期初DTA）_{计入损益部分}$

> [!example] 例题·综合题
> 甲公司2×24年度利润总额为$2000$万元，适用的所得税税率为$25\%$。当年发生的交易和事项中，会计处理与税法规定存在差异的有：
> （1）年末持有的交易性金融资产成本为$600$万元，公允价值为$660$万元；
> （2）年末计提存货跌价准备$50$万元；
> （3）当年确认的国债利息收入$30$万元；
> （4）当年发生的税收罚款$10$万元；
> （5）年末持有的其他权益工具投资成本为$800$万元，公允价值为$900$万元。
> 假定年初不存在暂时性差异余额。
>
> > [!check]- 答案与解析
> > **正确答案：**
> > 所得税费用为$497.5$万元。
> >
> > **深度解析：**
> > **第一步：计算当期所得税。**
> > 应纳税所得额 $= 2000 - 60（交易性金融资产公允价值上升）+ 50（存货跌价准备）- 30（国债利息免税）+ 10（罚款不可扣）- 100（其他权益工具投资公允价值上升，不调整，因为未计入会计利润）$
> >
> > 注意：其他权益工具投资的公允价值变动计入其他综合收益，**不影响会计利润**，也**不影响应纳税所得额**，所以不参与纳税调整。
> >
> > 应纳税所得额 $= 2000 - 60 + 50 - 30 + 10 = 1970$ 万元
> > 当期所得税 $= 1970 \times 25\% = 492.5$ 万元
> >
> > **第二步：计算递延所得税。**
> >
> > | 项目 | 暂时性差异 | 类型 | DTA/DTL | 对应科目 |
> > | :--- | :--- | :--- | :--- | :--- |
> > | 交易性金融资产 | $660-600=60$ | 应纳税 | DTL $=60×25\%=15$ | 所得税费用 |
> > | 存货 | $50$ | 可抵扣 | DTA $=50×25\%=12.5$ | 所得税费用 |
> > | 其他权益工具投资 | $900-800=100$ | 应纳税 | DTL $=100×25\%=25$ | **其他综合收益** |
> >
> > 计入所得税费用的递延所得税 $= 15 - 12.5 = 2.5$ 万元
> > 计入其他综合收益的递延所得税 $= 25$ 万元（不影响所得税费用）
> >
> > **第三步：计算所得税费用。**
> > 所得税费用 $= 492.5 + 2.5 = 495$ 万元
> >
> > **第四步：编制会计分录。**
> > 借：所得税费用　　　　　　　　　 495
> > 　　其他综合收益　　　　　　　　 25
> > 　　递延所得税资产　　　　　　　 12.5
> > 　贷：应交税费——应交所得税　　　 492.5
> > 　　　递延所得税负债　　　　　　 40
> >
> > **💡 易错点提示：**
> > 1. **国债利息和罚款属于永久性差异**，只影响当期所得税，不产生暂时性差异，不确认递延所得税。
> > 2. **其他权益工具投资**的递延所得税对应**其他综合收益**而非所得税费用，这是最容易出错的地方。
> > 3. 计算应纳税所得额时，只调整影响会计利润的项目。其他权益工具投资公允价值变动不影响利润表，所以不参与纳税调整。

# 7. 递延所得税的列报

## 7.1 资产负债表列报

| 项目 | 列报位置 |
| :--- | :--- |
| 递延所得税资产 | 非流动资产 |
| 递延所得税负债 | 非流动负债 |

**抵销条件：** 同一纳税主体、向同一税务机关缴纳所得税的递延所得税资产和递延所得税负债，在满足一定条件时，可以以抵销后的净额列示。

在合并财务报表中，纳入合并范围的企业之间，一方的当期所得税资产或递延所得税资产与另一方的当期所得税负债或递延所得税负债**一般不能予以抵销**，除非所涉及的企业具有以净额结算的法定权利并且意图以净额结算。
## 7.2 利润表列报

所得税费用在利润表中单独列示，包括当期所得税和递延所得税两个组成部分。

$\text{净利润} = \text{利润总额} - \text{所得税费用}$

## 7.3 所得税费用与会计利润的关系


理想情况：**所得税费用 = 利润总额 × 所得税税率**

但现实中这个等式经常不成立，原因是有些项目：
- 要么影响利润总额但不影响所得税
- 要么影响所得税但不影响利润总额
### 一、需要调整的两大类项目

 类型1：影响所得税，但不影响利润总额
- 税率变动影响递延所得税
- 使用前期未确认的可抵扣亏损
- 调整以前期间所得税（汇算清缴差异）
- 研发费用加计扣除

 类型2：影响利润总额，但不影响所得税
- 非应税收入（国债利息、财政拨款）
- 不可抵扣的成本费用（税收滞纳金、超标业务招待费）
- 本期未确认递延所得税资产的亏损/暂时性差异
### 二、不需要调整的两种情况

**情况1：同时影响利润总额和所得税** → 不用调
- 例：计提固定资产减值（既减少利润，又产生递延所得税资产）

**情况2：既不影响利润总额也不影响所得税** → 不用调
- 例：其他债权投资公允价值变动计入其他综合收益（不走利润表，也不确认递延所得税）

### 三、具体调整项目（4类）

 （1）税率变动

- 税率变动影响递延所得税费用
- 但这事儿不体现在利润总额里
- 所以需要在调节表里单独列示

 （2）永久性差异
包括：
- **非应税收入**（如国债利息）→ 减少所得税费用
- **不可抵扣项目**（如税收滞纳金、超标招待费）→ 增加所得税费用
- **加计扣除**（如研发费用）→ 减少所得税费用

**案例**：缴纳税收滞纳金100万
```
利润总额1000万，缴纳滞纳金100万后：
- 会计利润 = 1000 - 100 = 900万
- 应纳税所得额 = 900 + 100（调增）= 1000万
- 所得税费用 = 1000 × 25% = 250万

看吧，滞纳金虽然减少了会计利润，但税法不认，
所以实际税负率 = 250/900 = 27.78%（高于名义税率25%）
```

 （3）未确认/使用前期未确认的递延所得税资产

**本期未确认**：
- 企业发生亏损或可抵扣差异
- 但判断未来没有足够应纳税所得额
- 所以不确认递延所得税资产
- 结果：这部分亏损影响了利润总额，但没影响所得税费用 → 需要调增

**使用前期未确认**：
- 以前年度亏损当时没确认递延所得税资产
- 本期有了应纳税所得额，用这亏损抵了
- 结果：减少了当期所得税，但没影响本期利润总额 → 需要调减

**案例**：
```
前期亏损2000万（未确认递延所得税资产）
本期会计利润3000万

借：所得税费用 250
  贷：应交税费——应交所得税 250
    （3000 - 2000）× 25%

你看，前期亏损不在本期利润总额里，
但抵减了本期应纳税所得额，所以要调整。
```

 （4）汇算清缴差异
- 去年预计要交100万所得税
- 今年汇算清缴发现实际只需交90万
- 这10万差异要在今年调整
- 但不影响今年的利润总额
### 四、调节表结构（从会计利润到所得税费用）

| 序号 | 项目 | 调整方向 | 原因 |
|------|------|----------|------|
| 1 | 利润总额 | 起点 | - |
| 2 | 按母公司税率计算的所得税 | 基准 | 利润总额 × 母公司税率 |
| 3 | 子公司税率差异 | ± | 子公司利润 ×（子公司税率 - 母公司税率） |
| 4 | 调整以前期间所得税 | ± | 汇算清缴差异 |
| 5 | 非应税收入影响 | **-** | 非应税收入 × 税率 |
| 6 | 不可抵扣项目影响 | **+** | 不可抵扣金额 × 税率 |
| 7 | 使用前期未确认亏损 | **-** | 使用金额 × 税率 |
| 8 | 本期未确认递延所得税 | **+** | 未确认金额 × 税率 |
| 9 | 研发费用加计扣除 | **-** | 加计扣除金额 × 税率 |
| 10 | **所得税费用** | **终点** | 当期所得税 + 递延所得税 |


> [!example] 例题·多选题
> 下列属于调整项目的有（）
> 
> A. 本期确认上期未确认递延所得税资产的可抵扣亏损  
> B. 本期其他债权投资公允价值上升计入其他综合收益  
> C. 本期确认税法规定的非应税收入  
> D. 本期计提固定资产减值损失并确认递延所得税资产  
>
> > [!check]- 答案与解析
> > 
> > **正确答案：AC**
> >
> > **深度解析：**
> > 
> > **判断标准：** 调整项目是指**影响会计利润但不影响应纳税所得额**，或**不影响会计利润但影响应纳税所得额**的项目。
> >
> > **选项分析：**
> > 
> > **A选项 ✓**  
> > - 前期可抵扣亏损**不在本期利润总额**中反映
> > - 但本期用于抵减应纳税所得额→**影响当期所得税费用**
> > - 属于**只影响应纳税所得额，不影响利润总额**的调整项目
> >
> > **B选项 ✗**  
> > - 其他债权投资公允价值变动计入**其他综合收益**
> > - 既不在利润总额中，也**不确认递延所得税**（直接计入所有者权益）
> > - 不属于调整项目
> >
> > **C选项 ✓**  
> > - 非应税收入**已计入利润总额**
> > - 但税法规定**不计入应纳税所得额**（如国债利息收入）
> > - 属于**只影响利润总额，不影响应纳税所得额**的调整项目
> >
> > **D选项 ✗**  
> > - 固定资产减值损失**减少会计利润**
> > - 同时确认递延所得税资产**影响所得税费用**
> > - **两边都有影响**，不需要单独调整
> >
> > **💡 易错点提示：**
> > - 区分**调整项目**与**暂时性差异**：调整项目强调"单边影响"（只影响一方）
> > - **其他综合收益**项目通常不涉及所得税调整，除非后续转入损益
> > - **递延所得税资产/负债的确认**本身不是调整项目，而是差异的结果
