> [!note] 本章要点
> 1. 什么是政府补助？
> 2. 政府补助的分类
> 3. 会计处理的三个维度：总额法/净额法；日常活动有关/无关；资产相关/收益相关

## 一、概述

### 1. 定义

(选择题高频考察)

**政府补助**，是指企业从政府无偿取得货币性资产或非货币性资产。其主要形式包括政府对企业的无偿拨款、**税收返还**、财政贴息、无偿给予非货币性资产等。

| 情形                        | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| （1）直接减征、免征、增加计税抵扣额、抵免部分税额 | **通常情况下**，**直接减征、免征、增加计税抵扣额、抵免部分税额**等**不涉及资产直接转移**的经济资源，不适用政府补助准则。_免交__20%__企业所得税并未发生资产的直接转移，不应作为政府补助进行会计处理，_<br>但是，**部分减免税款**需要按照政府补助准则进行会计处理。如：<br>①属于一般纳税人的加工型企业根据税法规定招用自主就业退役士兵，并按定额扣减增值税的，应当将减征的税额计入当期损益（**其他收益**）。<br>借：应交税费——应交增值税（**减免税款**）<br>　贷：其他收益<br>②即征即退的增值税，先按规定缴纳增值税，然后根据退回的增值税税额，借记"银行存款"等科目，贷记"**其他收益**"科目。<br>借：银行存款/其他应收款<br>　贷：其他收益<br>③按规定**直接减免应交的增值税税额**，计入**其他收益**。<br>借：应交税费——应交增值税（**减免税款**）<br>　贷：其他收益 |
| （2）增值税出口退税                | 根据税法规定，在对出口货物取得的收入免征增值税的同时，退付出口货物前道环节发生的进项税额，增值税出口退税实际上是**政府退回企业事先垫付的进项税额**，所以**不属于政府补助**。                                                                                                                                                                                                                                                                                                                                          |

```
税收优惠 → 有没有"真金白银"流入企业？
           │
    ┌──────┴──────┐
    ↓             ↓
   有             无
    │             │
    ↓             ↓
再问：这钱是     不属于政府补助
"政府给的"还是   （直接减免、抵扣等）
"自己垫的"？
    │
 ┌──┴──┐
 ↓     ↓
政府给  自己垫
 ↓     ↓
政府    不属于
补助    （出口退税）
```
### 2. 特征

- 政府补助是来源于政府的经济资源。
	- 税收优惠 → 有没有实实在在经济资源流入企业？
	- 对于企业收到的**来源于其他方**的补助，如有确凿证据表明政府是补助的实际拨付者，其他方只起到代收代付作用的，则该项补助也属于来源于政府的经济资源。
- 政府补助是**无偿**的

> [!note]
> （1) 单向流动 vs. 双向交换
> - **政府补助（无偿）**：资产从政府流向企业，企业不需要向政府交付商品或服务。这是“单向”的。
> - **政府采购（有偿）**：政府支付资金，企业向政府交付商品或服务（如卖电脑给政府、为政府修路）。这是“双向”的交易，属于**互惠交易**，应适用**收入准则**，而非政府补助准则。
> 
>  (2) “无偿”不等于“无条件”
> - **附带条件**：政府给你钱，通常会要求你“必须用于购买环保设备”或“必须招收残疾人员工”。
> - **逻辑判断**：这些是**政策条件**（Policy Conditions），而不是**交易对价**（Exchange Consideration）。企业满足这些条件是为了符合政策导向，而不是在卖东西给政府。
> 
>  (3) 区别于“资本投入”
> - 如果政府以**所有者身份**向企业投入资金（如增资扩股），并享有相应的所有者权益（分红权、决策权），虽然企业也没有交付商品，但这属于**权益性交易**，计入“实收资本/股本”或“资本公积”，不属于政府补助。

### 3. 分类

- 与资产相关的政府补助
- 与收益相关的政府补助
```
政府补助 → 用来干什么？
          │
   ┌──────┴──────┐
   ↓             ↓
 买/建资产      补贴费用/损失
   ↓             ↓
与资产相关    与收益相关
```

> [!example] 例题·单选题
> (2016)甲公司自2×10年开始，受政府委托进口医药类特种丙原料，再将丙原料销售给国内生产企业，加工出丁产品并由政府定价后销售给最终用户，由于国际市场上丙原料的价格上涨，而国内丁产品的价格保持不变，形成进销价格倒挂的局面。2×14年之前，甲公司销售给生产企业的丙原料以进口价格为基础定价，国家财政弥补生产企业产生的进销差价；2×14年以后，国家为规范管理，改为限定甲公司对生产企业的销售价格，然后由国家财政弥补甲公司的进销差价。不考虑其他因素，从上述交易的实质判断，下列关于甲公司从政府获得进销差价弥补的会计处理中，正确的是（　）。
> 
> A. 确认为与销售丙原料相关的营业收入
> B. 确认为所有者的资本性投入计入所有者权益
> C. 确认为与收益相关的政府补助，直接计入当期营业外收入
> D. 确认为与资产相关的政府补助，并按照销量比例在各期分摊计入营业外收入
>
> > [!check]- 答案与解析
> > 
> > **正确答案：A**
> > 
> > **深度解析：**
> > 
> > **第一步：理解交易实质**
> > - 甲公司的角色：受政府委托进口丙原料，按政府限定价格销售给生产企业
> > - 核心问题：国际采购价格 > 国内限定销售价格，形成**进销价格倒挂**
> > - 政府弥补的是甲公司因执行政府定价而产生的**差价损失**
> > 
> > **第二步：判断是否属于政府补助**
> > 根据政府补助准则，政府补助是指企业从政府**无偿**取得货币性资产或非货币性资产。但本题中：
> > - 甲公司获得的差价弥补**并非无偿**，而是其销售丙原料的**对价组成部分**
> > - 实质上，甲公司的完整销售收入 = **生产企业支付的价款** + **政府弥补的差价**
> > 
> > **第三步：正确的会计处理**
> > 政府弥补的进销差价应作为甲公司销售丙原料的**营业收入**的一部分，而非政府补助。
> > 
> > **💡 易错点提示：**
> > 1. 不能仅因为资金来源于政府就认定为"政府补助"，需判断交易实质是否为**无偿取得**
> > 2. 本题政府弥补的差价本质上是**商品销售对价的补足**，属于日常经营活动产生的收入，应计入**营业收入**而非营业外收入

## 二、政府补助的会计处理

### 1. 会计处理方法

#### （一）政府补助的确认

根据政府补助准则的规定，政府补助**同时满足**下列条件的，才能予以确认：
1. 企业**能够满足**政府补助**所附条件**
2. 企业**能够收到**政府补助。
#### （二）政府补助的计量

**1. 货币性资产**

（1）如果企业**已经实际收到**补助资金，应当按照**实际收到的金额**计量；
（2）如果资产负债表日企业**尚未收到**补助资金，但企业在符合了相关政策规定后就相应获得了收款权，且与之相关的经济利益很可能流入企业，企业应当在这项补助成为应收款时按照**应收的金额**计量。（**其他应收款**）

**2. 非货币性资产**

政府补助为非货币性资产的，应按**公允价值**计量；公允价值不能可靠取得的，按照**名义金额**计量。

#### （三）政府补助的会计处理方法

**1. 会计处理方法**

（1）总额法
总额法，是指在确认政府补助时，将政府补助**全额一次或分次确认**为收益，而不是作为相关资产账面价值或者成本费用等的扣减。

（2）净额法
净额法，是指在确认政府补助时，将政府补助确认为对相关资产账面价值或者所补偿成本费用等的**扣减**。

**2. 会计处理方法不得随意变更**

企业应当根据经济业务的实质，判断**某一类**政府补助业务应当采用总额法还是净额法进行会计处理。通常情况下，对**同类或类似**政府补助业务只能选用一种方法；同时，企业对该业务应当一贯地运用该方法，不得随意变更。
政府补助会计处理方法的变更属于**会计政策变更**。

**3. 会计处理原则**

|  | 总额法 | 净额法 |
| --- | --- | --- |
| 与企业日常活动相关 | 其他收益 | 冲减相关成本费用 |
| 与企业日常活动无关 | 营业外收入 | 冲减营业外支出 |

### 2. 与资产相关的政府补助

#### （1）总额法（两条线）

总额法下，企业在取得与资产相关的政府补助时应当按照补助资金的金额借记"银行存款"等科目，贷记"**递延收益**"科目；然后在相关资产使用寿命内按合理、系统的方法分期计入损益。

企业采用**总额法**时，与资产相关的政府补助在摊销时也应尽可能与资产的消耗情况对应，即与相关资产折旧或摊销方法对应。例如，**当企业选择加速折旧法计提固定资产折旧时，因与该资产相关的政府补助而确认的递延收益也可加速摊销**。如果对应的长期资产在**持有期间发生减值损失**，**递延收益的摊销仍保持不变**，不受减值因素的影响。

**① 先取得政府补助，后确认长期资产**

如果企业**先取得**与资产相关的政府补助，再确认所购建的长期资产，总额法下应当**在开始对相关资产计提折旧或进行摊销时**按照**合理、系统的方法**将递延收益分期计入当期收益（其他收益或营业外收入）。

（所购建的长期资产以固定资产为例）
**步骤1：取得政府补助**

```
借：银行存款
　贷：递延收益
```

**步骤2：确认所购建的长期资产**

```
借：固定资产
　贷：银行存款等
```

**步骤3：按照固定资产的入账价值计提折旧**

```
借：制造费用等
　贷：累计折旧
```

**步骤4：在对固定资产计提折旧时按合理系统方法将递延收益分期计入当期收益**

```
借：递延收益
　贷：其他收益（与企业日常活动相关的政府补助）
　　　营业外收入（与企业日常活动无关的政府补助）
```

**② 先确认长期资产，后取得政府补助**

在相关资产剩余使用寿命内按照合理、系统的方法将递延收益分期计入当期收益。

**③ 相关资产在使用寿命结束时或结束前被处置**

相关资产在使用寿命结束时或结束前被处置（出售、转让、报废、毁损等），**尚未分配的相关递延收益余额应当转入资产处置当期的损益**，**不再予以递延**。

```
借：递延收益（尚未分配的递延收益余额）
　贷：资产处置损益
```

#### （2）净额法（一条线）

**① 先取得政府补助，后确认长期资产**

如果企业先取得与资产相关的政府补助，再确认所购建的长期资产的，净额法下应当将取得的政府补助先确认为**递延收益**，在相关资产达到预定可使用状态或预定用途时将递延收益冲减相关资产的账面价值，并按照冲减后的账面价值和相关资产的剩余使用寿命计提折旧或进行摊销。

（所购建的长期资产以固定资产为例）

**步骤1：收到补助资金**

```
借：银行存款
　贷：递延收益
```

**步骤2：确认所购建的长期资产**

```
借：固定资产
　贷：银行存款等
```

**步骤3：将取得的政府补助冲减固定资产的账面价值**

```
借：递延收益
　贷：固定资产
```

**步骤4：按照扣减政府补助后的固定资产账面价值计提折旧**

```
借：制造费用等
　贷：累计折旧
```

**② 先确认长期资产，后取得政府补助**

如果相关长期资产投入使用后企业再取得与资产相关的政府补助，净额法下应当**在取得补助时**冲减相关资产的账面价值，并按照**冲减后的账面价值和相关资产的剩余使用寿命**计提折旧或进行摊销。
### 3. 与收益相关的政府补助

**1. 补偿企业以后期间的相关成本费用或损失**

与收益相关的政府补助，如果用于补偿企业**以后期间**的相关成本费用或损失的，企业在取得时**应当先判断能否满足政府补助所附条件**。客观情况表明企业能够满足政府补助所附条件的，企业应将其确认为**递延收益**，并在确认相关成本费用或损失的期间，计入**当期损益**或**冲减相关成本费用**。

如果企业在收到补助资金时暂时无法确定能否满足政府补助所附条件，则应当将收到的补助资金先记入"**其他应付款**"科目，待客观情况表明企业能够满足政府补助所附条件后再转入"递延收益"科目。

**2. 补偿企业已发生的相关成本费用或损失**

与收益相关的政府补助，如果用于补偿企业**已发生的**相关成本费用或损失，则直接计入**当期损益**或**冲减相关成本费用**。
### 4. 政府补助的退回

**已确认的**政府补助需要退回的，应当在需要退回的当期分情况按照以下规定进行会计处理：**（"原路返回"原则）**
	（1）初始确认时冲减相关资产账面价值的，调整资产账面价值；
	（2）存在相关递延收益的，冲减相关递延收益账面余额，超出部分计入**当期损益**；
	（3）属于其他情况的，直接计入**当期损益**。

对于**属于前期差错的**政府补助退回（如企业被认定为以骗补的方式取得补助），应当按照前期差错更正进行追溯重述。

> 接承【教材例18-5】，假设2×19年5月，因客观环境改变，丁公司不再符合申请补助的条件，有关部门要求丁公司全额退回补助款。丁公司于当月退回了补助款210万元。
>
> > [!check]- 答案与解析
> >
> > **方法一：丁公司选择总额法对此类补助进行会计处理**
> >
> > 丁公司应当结转尚未分配的递延收益，并将超出部分计入当期损益。因为本例中该项补助与日常活动相关，所以这部分退回的补助冲减应退回当期的其他收益。
> >
> > 2×19年5月丁公司退回补助款时：
> >
> > ```
> > 借：递延收益　　　　（210-210/10）189
> > 　　其他收益　　　　　　　　　　　 21
> > 　贷：银行存款　　　　　　　　　　　210
> > ```
> >
> > **方法二：丁公司选择净额法进行会计处理**
> >
> > 丁公司应当视同一开始就没有收到政府补助，调整固定资产的账面价值，并补提折旧。2×19年5月丁公司退回补助款时：
> >
> > ```
> > 借：固定资产　　　　　　　　　　　210
> > 　贷：银行存款　　　　　　　　　　　210
> >
> > 借：制造费用/库存商品/主营业务成本 21
> > 　贷：累计折旧　　　　　　　　　　　 21
> > ```

### 5. 特定业务的会计处理

#### （1）综合性项目政府补助

综合性项目政府补助同时包含与资产相关的政府补助和与收益相关的政府补助，企业应当采取合理的方法将其进行分解并分别进行会计处理；确实难以区分的，企业应当将其整体归类为**与收益相关**的政府补助进行处理。
#### （2）政策性优惠贷款贴息

## 三、政府补助的列报

### 1. 政府补助在财务报表中的列示

#### （一）政府补助在资产负债表中的列示

计入递延收益的政府补助在资产负债表作为**非流动负债在"递延收益"项目**中单独列示。

> [!info] 提示
> 资产负债表的"递延收益"项目中摊销期限只剩一年或不足一年的，或预计在一年内（含一年）进行摊销的部分，不得归类为流动负债，仍在该项目中填列，**不转入"一年内到期的非流动负债"项目**。
#### （二）政府补助在利润表中的列示

1. 企业应当在利润表中的"营业利润"项目之上单独列报"其他收益"项目，计入其他收益的政府补助在该项目中反映。冲减相关成本费用的政府补助，在相关成本费用项目中反映。
2. 与企业日常经营活动无关的政府补助，在利润表的营业外收支项目中列报。
### 2. 政府补助的附注披露

因政府补助涉及递延收益、其他收益、营业外收入以及成本费用等多个报表项目，为了全面反映政府补助情况，企业应当在附注中单独披露与政府补助有关的下列信息：
（1）政府补助的种类、金额和列报项目；
（2）计入当期损益的政府补助金额；
（3）本期退回的政府补助金额及原因。
